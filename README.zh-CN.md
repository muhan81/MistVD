MistVD 是一款开源的 **安卓本地视频播放器**，基于 Kotlin 与 Jetpack Compose 开发，播放内核使用
AndroidX Media3 / ExoPlayer。它按**真实的文件夹结构**浏览你的存储，全程离线播放，并补上了一批原生体验里
没有的播放器能力 —— 包括 **实时美颜**、**最高 8 倍速与长按临时加速**、**无限循环随机播放**。

本项目是 [NekoVideo](https://github.com/FellipitoPV/NekoVideo) 的 **fork**，在原项目基础上继续开发并更名。
许可与署名见 [署名与许可](#署名与许可)。

⚠️ **升级前请先读这段：** 发布版 APK 使用**固定不变**的自签名密钥签名，所以在旧版本上直接覆盖安装新版本
**不会丢数据**。但如果换成**另一把密钥**签名的包（例如别人构建的版本），必须**先卸载**才能安装 —— 而卸载
会**清掉私密保险库的密码**，也就等于失去已移入保险库的文件。更换不同签名的安装包前，请务必先备份。

## 功能亮点

- 按文件夹浏览的本地视频库，不强制走"媒体库"视图
- Media3 / ExoPlayer 播放内核，支持画中画、迷你播放器、后台播放
- **实时美颜**：磨皮、美白、红润、锐化、亮度、对比度、饱和度
- **0.25x – 8x 倍速**，并支持**长按临时加速、松手复原**
- **无限循环随机播放**：记录已随机过的视频，点"下一个"永远不会走到头，也不会过快重复
- 四种播放模式：顺序播放 / 循环播放列表 / 单曲循环 / 随机播放
- 九宫格**工具箱**：批量打标签、随机播放、重命名、移动、删除、分享等
- 私密保险库：密码 / 指纹解锁、磁盘上文件名混淆、播放时不产生解密临时文件
- 视频标签：普通与私密两套独立作用域、自动备份、按标签随机播放
- DLNA / UPnP 投屏，不依赖任何闭源投屏 SDK
- 无广告、无统计、无云端依赖

## 美颜功能

美颜在**播放过程中实时生效**（不需要导出成品），作用在 Media3 的视频渲染管线里。共 7 个可调项：

| 参数 | 范围 | 说明 |
|---|---|---|
| 磨皮 | 0 – 100 % | 保边磨皮，发丝 / 眼睛 / 五官细节不会被抹掉 |
| 美白 | 0 – 100 % | |
| 红润 | 0 – 100 % | |
| 锐化 | 0 – 100 % | |
| 亮度 | −100 – +100 % | |
| 对比度 | −100 – +100 % | |
| 饱和度 | −100 – +100 % | |

- **全局参数**对所有视频生效；也可以为**某一个视频**单独设置参数覆盖。
  优先级为：**单视频 > 全局 > 全关**。
- **方案**：把一套参数命名保存，之后一键套用，也可以重命名 / 删除。
- 三个入口：播放器的**「更多操作」抽屉**、**九宫格工具箱**（会自动判断是否选中了单个视频）、以及
  **设置 → 美颜**。
- 总开关**默认关闭**。单视频参数随时都能调整和保存，**总开关一打开即刻生效**。
- **HDR 片源不会启用美颜**（自动识别 PQ / HLG）并给出提示 —— 磨皮着色器按 8-bit sRGB 假设编写，
  直接处理 HDR 数据会偏色。

磨皮 / 锐化的着色器内核移植自 [**GPUPixel**](https://github.com/pixpark/gpupixel)
（Apache License 2.0，© 2021 PixPark），详见[署名与许可](#署名与许可)。其余 5 项复用 Media3 内置效果。

## 具体功能

### 媒体库与文件管理

- 以真实文件夹结构浏览存储；扫描并缓存含视频的文件夹
- 常见格式：`mp4`、`mkv`、`webm`、`avi`、`mov`、`wmv`、`m4v`、`3gp`、`flv`
- 缩略图内存 + 磁盘双级缓存；支持在当前文件夹内搜索
- 支持按名称 / 日期 / 大小排序，可显示时长与文件大小
- 最多可固定 10 个文件夹作为快捷入口
- 新建文件夹、重命名、移动、删除、分享，支持在工具箱里批量操作
- **多存储卷支持**：可选择要浏览的存储卷（含 SD 卡），选择结果按卷 UUID 持久化
- **迁移向导**：把已有的私密保险库在存储卷之间搬迁
- 支持从其他应用通过 `VIEW` / `SEND_MULTIPLE` 打开视频

### 播放

- 文件夹播放与播放列表导航
- **无限循环随机**：记录已播放过的视频，反复点"下一个"始终能给出新视频并无限循环；
  返回上一个再点下一个，依然会随机出新的视频
- 双击快进 / 快退、连续双击叠加、上下滑调音量与亮度
- 倍速 **0.25x – 8x**；**长按画面任意位置临时加速**，松手恢复原速（加速倍数可在设置里调整）
- 四种播放模式：顺序播放 / 循环播放列表 / 单曲循环 / 随机播放
- 睡眠定时、播放时保持屏幕常亮、音轨与字幕轨选择、外挂字幕与字号调整
- 自动旋转；通过 `MediaSessionService` 支持后台播放
- 媒体通知与锁屏控制；浏览界面常驻迷你播放器
- 继续观看：首页卡片与文件夹内均可续播，并恢复音轨 / 字幕轨 / 外挂字幕选择

### 私密保险库

- 密码保护，设置密码后可启用指纹解锁
- **连点左上角应用图标 3 次**即可调出解锁入口，输入密码进入
- 解锁框支持「**输对即进**」：密码正确会**自动提交**，无需再点「验证」；
  密码错误时**不弹任何提示**，只有点击「验证」才会提示密码错误
- 文件名与目录名替换为 UUID，并写入 `.nomedia` 阻止其他应用扫描；
  每个文件的前 8 KB 做 XOR 混淆，抹掉容器特征字节
- 播放时通过自实现的数据源**边读边还原**，**磁盘上不会产生解密后的临时明文文件**
- 未解锁时**完全不渲染**私密内容（不是置灰），冷启动自动回到隐藏状态

> **安全说明（请务必阅读）：** 这是**防窥级别的保护，不是完整的加密**。每个文件只有前 8 KB 做了混淆，
> 视频主体仍以原始数据存放；保险库的密钥派生自你的密码，但 salt 以明文存放在保险库旁边。
> 请把它当作防人眼偷窥的手段，而不是对抗取证级攻击的加密方案。

### 投屏

- 通过 SSDP 发现局域网内的 DLNA / UPnP 接收端，用内置 HTTP 服务串流本地文件
- 支持播放列表投屏、上一个 / 下一个控制、播放状态轮询
- 不依赖 Google Cast SDK

### 标签

- 新建、重命名、删除标签；可给单个或多个视频打标签
- 普通内容与私密内容使用两套独立作用域
- 按标签随机播放，支持「用于随机播放 / 忽略 / 中性」三种过滤
- 重命名或移动文件后标签引用仍然有效；设备内自动备份，支持导入 / 合并 / 导出

### 设置

- 播放：后台播放、控制栏自动隐藏、快进手势、音量亮度手势、长按加速倍数、继续观看、睡眠定时
- 界面：主题（浅色 / 深色 / 跟随系统，深色为纯黑 AMOLED）、应用语言
- 显示：时长与文件大小的显示方式
- 存储：缩略图缓存、继续观看记录、存储卷选择
- 安全：修改密码、指纹解锁
- **美颜**：总开关、7 个参数、方案管理
- 标签管理：备份与恢复

## 技术栈

| 层次 | 技术 |
|---|---|
| 语言 | Kotlin 2.1 + Coroutines |
| 界面 | Jetpack Compose + Material 3 |
| 播放 | AndroidX Media3 / ExoPlayer 1.7.1（含 media3-effect） |
| 后台媒体 | MediaSessionService |
| 导航 | Navigation Compose |
| 缩略图 | Coil、Glide、MediaMetadataRetriever |
| 本地数据库 | Room |
| 序列化 | Gson |
| 投屏 | DLNA / UPnP（SSDP + SOAP） |
| 局域网串流 | NanoHTTPD |
| 构建 | Gradle 8.13（Kotlin DSL）+ AGP 8.13 |

## 环境要求

- Android 11（API 30）或更高
- 需要访问本地存储；按文件夹浏览的模式在部分系统上需要「所有文件访问权限」
- 打包的 APK **仅包含 `arm64-v8a`**

## 构建

```bash
./gradlew assembleRelease
```

发布构建会开启 R8 混淆，并使用 `app/release-signing.properties` 指向的密钥库签名（该文件不在仓库里）。
没有签名配置时请改用 `assembleDebug`。

项目信息：

- `minSdk = 30`，`targetSdk = 36`
- `versionName = "1.20"`，`versionCode = 46`

## 隐私

MistVD 不含统计、广告或第三方追踪。网络活动仅限局域网投屏（DLNA 发现与播放控制）。
缩略图生成、标签存储、私密保险库处理全部在设备本地完成。
